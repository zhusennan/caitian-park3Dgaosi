# 彩田公园数字孪生 · 数据对接清单与演示说明

> 配合 Demo 一同提交客户，用于对齐后续实施所需的数据与接口。

## 一、Demo 已实现的能力（对应需求优先级）

| 优先级 | 需求点 | Demo 状态 | 备注 |
|---|---|---|---|
| P0 | 3D 高斯实景重建（空中 + 地面采集，约 5 万㎡） | ✅ 已实现 | 45 万高斯点实景底座，覆盖 5 个功能区 |
| P0 | 监控摄像头图层（46 点位，点击查看详情） | ✅ 已实现 | 点击中间弹窗展示真实园区画面，含设备参数、上一路/下一路切换、点位列表检索与筛选 |
| P1 | 人员分布热力图（纯密度，不含业务信息） | ✅ 已实现 | 24h 时段联动，可拖动时间轴播放 |
| P1 | 事件分布热力图（纯密度，不含业务信息） | ✅ 已实现 | 独立色阶与时段分布 |
| P2 | 管网展示图层（地上 + 地下） | ✅ 已实现 | X 射线透视、埋深标注、管线属性查询 |

Demo 中园区地形、道路、植被、建筑、车辆等为**按需求口径程序化生成的示意模型**，
用于验证图层叠加、交互与业务流程；正式实施时替换为真实采集成果与真实业务数据。
摄像头画面已使用园区实拍照片渲染，接入真实视频流后替换播放源即可。

## 二、需要公园侧提供的资料（已发出，待回收）

### 1. 监控点位（P0，优先级最高）
- [ ] 设备实施清单：设备编号、型号、类型（球机/枪机/半球）、分辨率、码流、安装日期
- [ ] 详细安装点位：点位坐标（GIS 坐标或 CAD 图纸）、立杆高度、朝向/覆盖角度
- [ ] 现网拓扑：平台地址、摄像机 IP 段、接入协议（GB28181 / ONVIF / RTSP）、NVR 清单
- [ ] 存储与录像策略：存储周期、回放要求、是否需与既有园区平台双向联动
> 说明：Demo 中「在线 41 / 离线 5」为示意状态，真实状态需以实施清单为准。

### 2. 3D 高斯实景重建（P0）
- [ ] 园区范围红线（CAD / 矢量 shp），用于裁切重建范围
- [ ] 地面采集路线与空中航线确认（Demo 中已给出示意方案：空中 12 架次 + 地面 3 组）
- [ ] 采集时段要求（是否需要人流高峰时段采集，用于热力图校准）
- [ ] 精度验收标准（建议 ±5cm，对应 5cm/px 分辨率）

### 3. 热力图数据（P1）
- [ ] 人员密度：客流感知/AI 视频分析系统的聚合输出（建议 5m×5m 网格，单位 人/㎡）
- [ ] 事件密度：事件中心按空间聚合的输出（建议 5m×5m 网格，单位 起/㎡）
- [ ] 接口形式：API 拉取 / 数据库直连 / 离线文件推送；数据更新频率（Demo 按 5 分钟滚动）
- [ ] 明确：热力图层仅渲染空间密度，不叠加任何业务明细字段

### 4. 管网数据（P2）
- [ ] 地下管线探测成果（给水/雨水/污水/电力/通信）：管径、材质、埋深、起讫点坐标
- [ ] 地上设施：架空线路走向、照明桥架/综合管沟位置、地面箱变与配电箱坐标
- [ ] 竣工图或 CAD 管线图（若仅有纸质图，需提供电子化坐标）

## 三、接口与系统对接方案（建议）

```
[海康 NVR/平台]  ──GB28181 / ONVIF / RTSP──▶  ┐
[自研视频平台]  ◀──统一切换、录像回放联动──    ┤
                                                ├──▶ [数字孪生平台 Demo / 正式系统]
[客流感知系统]  ──空间聚合密度──▶               │      ├─ 3D 高斯实景底座
[事件中心]      ──空间聚合密度──▶               │      ├─ 监控图层（点位/详情/联动）
[管线探测成果]  ──矢量/管段──▶                  │      ├─ 热力图层（人员/事件）
                                                │      └─ 管网图层（地上/地下）
[公园既有平台]  ◀──事件回推 / 处置闭环──         ┘
```

- 所有图层统一使用**园区局部平面坐标**（与 3D 高斯模型同一坐标系），便于业务数据直接空间叠加；
- 热力数据建议在服务端完成网格聚合，前端只接收栅格/瓦片，避免传输明细数据。

## 四、演示环境

- Demo 为纯前端程序，已内置 three.js，**无需联网、无需后端**；
- 运行：目录下执行 `python3 -m http.server 4173`，浏览器访问 `http://127.0.0.1:4173/index.html`；
- 建议演示分辨率 1920×1080，浏览器窗口宽度 ≥ 1280px；
- 演示时提前预热页面（约 3.5 秒生成点云），避免现场等待。

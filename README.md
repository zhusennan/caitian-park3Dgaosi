# 彩田公园 · 三维实景数字孪生平台 Demo

面向客户演示的产品原型，覆盖《彩田公园需求对接》中 P0 / P1 / P2 全部需求点。
纯前端实现（three.js + WebGL2），无需后端与网络，打开即用。

---

## 一、运行方式

```bash
cd caitian-park-demo
python3 serve.py            # 默认 4173，禁用缓存，改完代码刷新即生效
# 浏览器打开 http://127.0.0.1:4173/index.html
```

> `serve.py` 只比 `python3 -m http.server` 多了一件事：强制 `Cache-Control: no-store`，
> 避免浏览器缓存旧的 `js/*.js` 模块（模块用了 `?v=` 版本号，改代码后仍可能拿到旧文件）。

> ⚠️ 必须通过 HTTP 服务打开。由于使用 ES Module + importmap，直接双击 `index.html`（file:// 协议）会被浏览器 CORS 策略拦截。

推荐浏览器：Chrome / Edge / Safari 最新版，窗口宽度 ≥ 1280px（可获得完整三栏布局）。

## 二、需求对照表

| 优先级 | 需求 | Demo 中的实现 | 位置 |
|---|---|---|---|
| **P0** | 3D 高斯实景重建（空中+地面采集，5 万㎡） | 45 万高斯点程序化实景底座，覆盖 5 个功能区 | 左栏「实景底座」 |
| **P0** | 监控摄像头图层（46 个点位，点击查看详情） | 46 路三维点位（立杆 + 云台 + 视域锥 + 编号牌）；**在 3D 场景上直接点击编号牌，或点击列表中的任意点位**，即在屏幕中央弹窗展示该机位的**实景取景画面**（由 3D 高斯场景按该点位机位/朝向实时渲染取景，16:9 不裁切）+ 设备参数 + 上一路/下一路切换；**监控点位列表**支持编号/名称/区域搜索、按状态与区域筛选 | 3D 场景点位、右侧列表、工具栏「监控点位列表」 |
| **P1** | 人员分布热力图（纯密度） | 贴地密度场 + 色阶渲染，24 小时时段曲线联动，时间轴播放 | 左栏「人员分布热力图」 |
| **P1** | 事件分布热力图（纯密度） | 独立密度场 + 事件类型占比统计 | 左栏「事件分布热力图」 |
| **P2** | 管网图层（地上 + 地下） | 13 条管线（电力/给水/雨水/污水/通信/架空），地上实线 + 地下虚线；**打开「地下管网」即自动进入地表半透明透视并展示管网，关闭即退出**（工具栏「地下管网透视」与左侧开关双向联动）；埋深标注、点击查看管径/材质/埋深/长度 | 左栏「地上管网」「地下管网」、工具栏「地下管网透视」 |

### 演示动线（10 分钟）

1. **开场（1 min）** — 默认全景视角，说明这是 5 万㎡ 园区的 3D 高斯实景重建底座。
2. **P0 监控点位（3 min）** — 在 3D 场景上直接点击任意编号牌 → 相机自动飞至点位 → **屏幕中央弹窗展示该机位的实景取景画面**（画面即该点位在 3D 场景中实际能看到的视角，树木/设施已按视域做净空处理）与设备参数，可用「上一路 / 下一路」连续切换；再打开工具栏「监控点位列表」，演示搜索（编号/名称/区域）、按状态与区域筛选，以及单击任意点位自由切换。
3. **P1 热力图（2 min）** — 打开人员热力图 → 拖动底部时间轴观察密度随时段变化；切到事件热力图对比差异；关闭热力图时右侧抽屉自动回到园区总览。
4. **P2 管网（2 min）** — 打开「地上管网」→ 再打开「地下管网」→ 地表自动半透明、地下管线虚线浮现（再关闭即退出透视）；点击管线查看埋深与管径。
5. **收尾（1 min）** — 正射俯视图 + 工具栏「平面索引」小地图，说明后续数据对接方式。

## 四、接入真实数据

Demo 中所有数据均为按需求沟通口径构造的**示意数据**，接入真实数据时只需替换数据层：

| 数据 | 替换位置 | 需要的资料 |
|---|---|---|
| 摄像头清单与坐标 | `js/data.js` → `CAM_RAW` | 设备实施清单（编号/型号/分辨率）、安装点位坐标（GIS 或 CAD 坐标转换） |
| 管网 | `js/data.js` → `PIPES` | 竣工图/管径/埋深/材质，地下管线探测成果 |
| 人员密度 | `js/data.js` → `PEOPLE_SPOTS` + `heat.js` | 客流感知系统输出的 5m 网格密度（或直接给到栅格热力瓦片） |
| 事件密度 | `js/data.js` → `EVENT_SPOTS` | 事件中心按 5m 网格聚合的数据 |
| 实景模型 | `js/park.js` → `buildParkScene` | 替换为真实 `.ply` / `.splat` 高斯数据（42M 点规模需分块流式加载 + LOD） |

### 真实高斯数据接入建议
1. 保留本 Demo 的图层、交互与业务面板，仅替换渲染底座；
2. 高斯点用 `InstancedBufferGeometry` + 排序分块加载，避免一次性上传 4000 万点；
3. 相机点位、热力面、管线均使用世界坐标（EPSG 转换后统一到园区局部坐标），可与实景模型共用同一坐标系。
